# Code of Conduct

This project is committed to providing a welcoming and respectful environment for contributors and users.

## Expected behavior

- Be respectful and constructive in discussions.
- Assume good intent and communicate clearly.
- Help maintain a safe, inclusive space for all participants.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Trolling, spam, or disruptive behavior.
- Publishing private information without consent.

## Enforcement

Report concerns to the project maintainer through the repository issue tracker or private contact.
